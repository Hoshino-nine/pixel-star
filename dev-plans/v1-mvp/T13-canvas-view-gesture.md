# [v1 / T13] 画布手势（缩放/平移）

| 项 | 值 |
| --- | --- |
| 所属版本 | v1-mvp |
| 预计工时 | 4-6 h |
| 前置依赖 | T04, T03 |
| 涉及目录 | `src/ui/canvas_view.cpp` |

## 目标
实现画布视图的缩放（鼠标滚轮 / 双指捏合）、平移（中键拖动 / 双指拖动），坐标变换正确，工具事件转换到画布坐标系。

## 主要产出
- `src/ui/canvas_view.h/.cpp`：`CanvasView { Camera camera; handleEvent(...) }`
- `src/ui/canvas_view.cpp` 内置：双指手势识别（基于 SDL_FINGER 多点）
- 把 `InputEvent`（窗口坐标）转换为画布像素坐标（含越界裁剪）
- 缩放范围：0.25x ~ 32x

## 验收标准 (DoD 大纲)
- [ ] 桌面：滚轮缩放，中键拖动平移
- [ ] Android：双指捏合缩放，双指拖动平移；单指仍走工具事件
- [ ] 单指与双指切换平滑，不会触发误绘画
- [ ] 缩放以光标 / 双指中心为锚点（zoom-to-cursor）
- [ ] 缩放 ≥ 8x 时显示像素网格（启用 grid shader）
- [ ] 工具坐标转换正确：在缩放/平移后点击仍命中正确像素
- [ ] 编译通过 / 无新 lint 警告

## 备注
- 决策点：双指捏合的判定阈值？建议第二指落下后 100ms 内判定为手势模式
- 单指拖动的工具事件 vs 单指平移：MVP 先固定单指=工具，平移仅双指或中键
- 风险：Android 触摸坐标可能包含系统手势区域，T16 校准
